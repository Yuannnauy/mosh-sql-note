# 第三章 联表查询

## INNER JOIN 内连接（两个表在同一数据库）

将订单表和顾客表连接，按 customer_id 匹配：

```sql
SELECT *
FROM orders
JOIN customers
    ON orders.customer_id = customers.customer_id;
```

> 若在 SELECT 中选中 customer_id，必须指明是哪个表的，否则会报错。

```sql
-- 错误写法：
SELECT customer_id

-- 正确写法：
SELECT orders.customer_id
```

给表起别名简化输入：

```sql
SELECT order_id, o.customer_id, first_name, last_name
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id;
```

练习：

```sql
SELECT order_id, p.product_id, name, quantity, unit_price
FROM order_items oi
JOIN products p
    ON oi.product_id = p.product_id;
```

## 跨数据库连接（两个表在不同数据库）

```sql
-- 当前选中 sql_store 数据库
USE sql_store;
SELECT *
FROM order_items oi
JOIN sql_inventory.products p
    ON oi.product_id = p.product_id;

-- 当前选中 sql_inventory 数据库
USE sql_inventory;
SELECT *
FROM products p
JOIN sql_store.order_items oi
    ON oi.product_id = p.product_id;
```

> 只需给不在当前数据库的表加前缀。

## 自连接（Self Join）

在员工表中查看每位员工汇报对象的信息：

```sql
USE sql_hr;

SELECT
    e.employee_id,
    e.first_name,
    m.first_name AS manager
FROM employees e
JOIN employees m
    ON e.reports_to = m.employee_id;
```

## 多表连接

```sql
USE sql_store;

SELECT
    o.order_id,
    o.order_date,
    c.first_name,
    c.last_name,
    os.name AS status
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id
JOIN order_statuses os
    ON o.status = os.order_status_id;
```

练习：

```sql
USE sql_invoicing;

SELECT
    p.date,
    p.invoice_id,
    p.amount,
    c.name,
    pm.name
FROM payments p
JOIN clients c
    ON p.client_id = c.client_id
JOIN payment_methods pm
    ON p.payment_method = pm.payment_method_id;
```

## 复合连接条件

当单独一列无法独立识别一行数据时，用两列结合来唯一识别。

例如：order_items 表中 order_id 和 product_id 组合为复合主键。

```sql
SELECT *
FROM order_items oi
JOIN order_item_notes oin
    ON oi.order_id = oin.order_id
    AND oi.product_id = oin.product_id;
```

## 隐式连接语法（Implicit Join Syntax）

```sql
-- 标准写法：
SELECT *
FROM orders o
JOIN customers c
    ON o.customer_id = c.customer_id;

-- 隐式写法：
SELECT *
FROM orders o, customers c
WHERE o.customer_id = c.customer_id;
```

> 不推荐用隐式，因为一旦忘记 WHERE 就会变成交叉连接。

## 外连接（Outer Join）

内连接只能看到有 order 的 customers，想看到所有 customers 需要用外连接。

**LEFT JOIN**：左表所有记录都会被返回。

```sql
SELECT
    c.customer_id,
    c.first_name,
    o.order_id
FROM customers c
LEFT JOIN orders o
    ON c.customer_id = o.customer_id
ORDER BY c.customer_id;
```

**RIGHT JOIN**：右表所有记录都会被返回。

```sql
SELECT
    c.customer_id,
    c.first_name,
    o.order_id
FROM orders o
RIGHT JOIN customers c
    ON c.customer_id = o.customer_id
ORDER BY c.customer_id;
```

练习：

```sql
SELECT
    p.product_id,
    p.name,
    oi.quantity
FROM products p
LEFT JOIN order_items oi
    ON p.product_id = oi.product_id;
```

## 多表外连接

```sql
SELECT
    c.customer_id,
    c.first_name,
    o.order_id,
    sh.name AS shipper
FROM customers c
LEFT JOIN orders o
    ON c.customer_id = o.customer_id
LEFT JOIN shippers sh
    ON o.shipper_id = sh.shipper_id
ORDER BY c.customer_id;
```

练习：

```sql
SELECT
    o.order_date,
    o.order_id,
    c.first_name AS customer,
    sh.name AS shipper,
    os.name AS status
FROM orders o
LEFT JOIN customers c
    ON o.customer_id = c.customer_id
LEFT JOIN shippers sh
    ON o.shipper_id = sh.shipper_id
JOIN order_statuses os
    ON o.status = os.order_status_id;
```

## 自外连接（Self Outer Join）

找出所有员工汇报的上级（包括CEO）：

```sql
USE sql_hr;

SELECT
    e.employee_id,
    e.first_name,
    m.first_name AS manager
FROM employees e
LEFT JOIN employees m
    ON e.reports_to = m.employee_id;
```

> 如果用内连接，reports_to 为 NULL 的 CEO 信息将不会显示。

## USING 子句

如果两个表中有列名称完全一样，可以用 USING 简化（内外连接均适用）：

```sql
-- 原本写法：
JOIN customers c
    ON o.customer_id = c.customer_id

-- 简化：
USING (customer_id)
```

简化复合主键的连接：

```sql
-- 原本写法：
SELECT *
FROM order_items oi
JOIN order_item_notes oin
    ON oi.order_id = oin.order_id
    AND oi.product_id = oin.product_id;

-- 简化：
SELECT *
FROM order_items oi
JOIN order_item_notes oin
    USING (order_id, product_id);
```

练习：

```sql
USE sql_invoicing;

SELECT
    p.date,
    c.name AS client,
    p.amount,
    pm.name AS payment_method
FROM payments p
JOIN clients c
    USING (client_id)
JOIN payment_methods pm
    ON p.payment_method = pm.payment_method_id;
```

## 自然连接（Natural Join）

不建议使用，数据库会自动选择共同的列进行连接：

```sql
SELECT *
FROM orders o
NATURAL JOIN customers c;
```

## 交叉连接（Cross Join）

用于连接两个表的所有记录（笛卡尔积）：

```sql
-- 显式：
SELECT *
FROM customers c
CROSS JOIN products p;

-- 隐式（这就是隐式连接没有 WHERE 的情况）：
SELECT *
FROM customers c, products p;
```

练习：

```sql
-- 显式
SELECT *
FROM shippers sh
CROSS JOIN products p;

-- 隐式
SELECT *
FROM shippers sh, products p;
```

## 联合（UNION）

连接多张表的行：

```sql
SELECT
    order_id,
    order_date,
    'Active' AS status
FROM orders
WHERE order_date >= '2019-01-01'

UNION

SELECT
    order_id,
    order_date,
    'Archive' AS status
FROM orders
WHERE order_date < '2019-01-01';
```

UNION 可以合并同张表或不同表的查询结果：

```sql
SELECT first_name
FROM customers

UNION

SELECT name
FROM shippers;
```

> UNION 时选择的列数量要相同。UNION 的列名与第一段查询的列名相同。

练习：

```sql
SELECT
    customer_id,
    first_name,
    points,
    'Bronze' AS type
FROM customers
WHERE points < 2000

UNION

SELECT
    customer_id,
    first_name,
    points,
    'Silver' AS type
FROM customers
WHERE points BETWEEN 2000 AND 3000

UNION

SELECT
    customer_id,
    first_name,
    points,
    'Gold' AS type
FROM customers
WHERE points > 3000

ORDER BY first_name;
```
