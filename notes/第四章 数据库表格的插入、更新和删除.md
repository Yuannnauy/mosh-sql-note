# 第四章 数据库表格的插入、更新和删除

## 列属性

| 属性 | 说明 |
|------|------|
| PK | Primary Key，主键 |
| NN | Not Null，该列不可存储 NULL 值 |
| AI | Auto Increment，自动递增，通常用于主键 |
| Default/Expression | 该列没输入信息时的默认值 |

- `VARCHAR(50)`：最多可储存50字符，小于50时只存储真实字符数大小
- `CHAR(50)`：不管存储多少字符，都会占用50字符空间

## 插入单行

```sql
-- 方式一：按表列顺序插入，自动递增列用 DEFAULT
INSERT INTO customers
VALUES (DEFAULT, 'John', 'Smith', '1990-01-01', NULL, 'address', 'city', 'CA', DEFAULT);

-- 方式二：指定要插入的列
INSERT INTO customers (first_name, last_name, birth_date, address, city, state)
VALUES ('John', 'Smith', '1990-01-01', 'address', 'city', 'CA');

-- 可以给列重新排序填入信息
INSERT INTO customers (last_name, first_name, birth_date, address, city, state)
VALUES ('Smith', 'John', '1990-01-01', 'address', 'city', 'CA');
```

## 插入分层行（往多表插入数据）

当两个表有子母关系，需要同时往两张表插入数据时：

```sql
-- 先插入母表（orders）
INSERT INTO orders (customer_id, order_date, status)
VALUES (1, '2019-01-02', 1);

-- LAST_INSERT_ID()：返回插入新行时生成的ID
-- 再插入子表（order_items）
INSERT INTO order_items
VALUES
    (LAST_INSERT_ID(), 1, 1, 2.95),
    (LAST_INSERT_ID(), 2, 1, 3.95);
```

## 插入表复制

从一张表复制数据到另一张表：

```sql
-- 将 orders 表复制一份为 orders_archived
CREATE TABLE orders_archived AS
SELECT * FROM orders;

-- 向已有表格添加数据
TRUNCATE TABLE orders_archived;  -- 先清空表数据

-- 插入 2019 年以前的订单信息
INSERT INTO orders_archived
SELECT *
FROM orders
WHERE order_date < '2019-01-01';
```

练习：

```sql
-- 创建 invoices_archived 表，存入 invoices 中的部分记录
-- 要求：
-- 1. 替换 invoices 中的 client_id 为 client_name
-- 2. 只筛选已经支付过的发票信息
CREATE TABLE invoices_archived AS
SELECT
    i.invoice_id,
    i.number,
    c.name AS client,
    i.invoice_total,
    i.payment_total,
    i.invoice_date,
    i.payment_date,
    i.due_date
FROM invoices i
LEFT JOIN clients c
    USING (client_id)
WHERE i.payment_date IS NOT NULL;
```

## 更新单行

```sql
UPDATE invoices
SET payment_total = 0, payment_date = NULL
WHERE invoice_id = 1;

UPDATE invoices
SET
    payment_total = invoice_total * 0.5,
    payment_date = due_date
WHERE invoice_id = 3;
```

## 更新多行

```sql
-- 更新所有 client_id = 3 的客户的信息
UPDATE invoices
SET
    payment_total = invoice_total * 0.75,
    payment_date = due_date
WHERE client_id = 3;

-- 使用 IN 关键字，更新所有 client_id = 3 和 4 的客户
UPDATE invoices
SET
    payment_total = invoice_total * 0.8,
    payment_date = due_date
WHERE client_id IN (3, 4);
```

练习：

```sql
-- 给1990年以前出生的顾客增加50积分
UPDATE customers
SET points = points + 50
WHERE birth_date < '1990-01-01';
```

## 在 UPDATE 中用子查询

```sql
UPDATE invoices
SET
    payment_total = invoice_total * 0.88,
    payment_date = due_date
WHERE client_id = (
    SELECT client_id
    FROM clients
    WHERE name = 'Myworks'
);
```

练习：

```sql
-- 为积分超过3000的顾客更新订单里的注释信息为 'Golden'
UPDATE orders
SET comments = 'Golden'
WHERE customer_id IN (
    SELECT customer_id
    FROM customers
    WHERE points > 3000
);
```

## 删除行

```sql
-- 删除客户名称为 'Myworks' 的发票信息
DELETE FROM invoices
WHERE client_id = (
    SELECT client_id
    FROM clients
    WHERE name = 'Myworks'
);
```
