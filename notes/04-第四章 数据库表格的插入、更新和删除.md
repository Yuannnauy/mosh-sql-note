## 列属性

<img width="302" height="114" alt="image" src="https://github.com/user-attachments/assets/f791d943-008b-48e2-a8ea-5fab0b83408b" />

| 属性 | 说明 |
|------|------|
| PK | Primary Key，主键 |
| NN | Not Null，该列不可存储 NULL 值 |
| AI | Auto Increment，自动递增，通常用于主键 |
| Default/Expression | 该列没输入信息时的默认值 |

- `VARCHAR(50)`：最多可储存50字符，小于50时只存储真实字符数大小
- `CHAR(50)`：不管存储多少字符，都会占用50字符空间



## 插入单行

```sql
-- 方式一：按表列顺序插入，自动递增列用 DEFAULT
--（设置了自动递增，可以用default让表自动生成唯一值）
INSERT INTO customers
VALUES (DEFAULT, 'John', 'Smith', '1990-01-01', NULL, 'address', 'city', 'CA', DEFAULT);

-- 方式二：指定要插入的列
INSERT INTO customers (first_name, last_name, birth_date, address, city, state)
VALUES ('John', 'Smith', '1990-01-01', 'address', 'city', 'CA');

-- 可以给列重新排序填入信息
INSERT INTO customers (last_name, first_name, birth_date, address, city, state)
VALUES ('Smith', 'John', '1990-01-01', 'address', 'city', 'CA');
```

## 创建表复制

把一张表的数据复制到另一张表

但是这样的表没有主键

## 更新单行
```sql
update invoices
set payment_total=10, payment_date='2019-03-01'
where invoices_id=1
-- 如果该列允许输入null或者设有default值 可以
update invoices
set payment_total=default, payment_date=null
where invoices_id=1
-- 可以将单行更新的值用公式表示：
update invoices
set
       payment_total=invoice_total*0.5,
       payment_date=due_date
where invoices_id=3
```

## 更新多行

```sql
update invoices
```

## 在updates中子查询
```sql
update invoices
set
       payment_total=invoice_total*0.5,
       payment_date=due_date
where client_id=
       (select client_id
       from clients
       where name='myworks')
-- 子查询条件包换并返回多项：
update invoices
set
       payment_total=invoice_total*0.5,
       payment_date=due_date
where client_id in
       (select client_id
       from clients
       where state in ('CA','NY'))
-- exercise
update orders
set comment='gold customer'
where customer_id in
(select customer_id
from customers
where points>3000)
```
