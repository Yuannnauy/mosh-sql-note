# 窗口函数
来自：https://www.youtube.com/watch?v=Ww71knvhQ-s&list=PLavw5C92dz9GbmgiW4TWVnxhjMFOIf0Q7  
## 聚合函数
- 找到employee表中的最高工资者，并按照部门分类：可用聚合函数+group by
  ```sql
  select dept_name, max(salary) as max_salary
  from employee
  group by dept_name
  ```
  ## partition by 分区
  想显示更多详细信息 用窗口函数最容易实现:</br>
  显示表内所有信息 并显示每一名雇员所在部门最高工资：
  ```sql
  select e.*,
  max(salary) over(partition by dept) as max_salary
  -- max(salary) over()会把聚合函数max（）变为窗口函数，over（*）代表以*为窗口，例如over（）将会给每一行都开一个窗口，over(partition by dept)将以dept开窗口，不同的dept是不同的窗口
  from employee e;
  ```
  ## row_number 行号函数
  按照部门给行编号一个不重复的值 即 同一部门往后编号 直到不是同一部门 重置编号再次从1开始：
  ```sql
  select e.*,
  row_number() over(partiton by dept_name) as rn
  from employee e
  ```
  应用：想要找到每个部门最先加入（即员工id最小）的两名员工：</br>
  思路：按照部门给行编号，且每个部门内编号顺序要按照员工id顺序 最后子查询行号为1和2的员工
```sql
select *
  from(select *,
  row_number() over(partition by dept_name order by emp_id) as rn
  from employee e) x
where x.rn<3
```
## rank
找到每个部门薪水前三名员工：用rank进行排名，如果两个人薪水一样将值一样 但下面一个人会跳值 例如：1 2 2 4 或者 1 2 2 2 5
```sql
select* from (
select e.*，
rank() over(aprtition by dept_name order by salary desc) as rnk
from employee e) x
where x.rnk<4
```
## dense_rank
找到每个部门薪水前三名员工：用dense_rank进行排名，如果两个人薪水一样将值一样 但下面一个人不会跳值 例如：1 2 2 3 或者 1 2 2 2 3
```sql
select e.*，
rank() over(aprtition by dept_name order by salary desc) as rnk
dense_rank() over(aprtition by dept_name order by salary desc) as dense_rnk
from employee e
```
## lag & lead
检查后一个员工工资是否高于或低于前一位:用lag新创建一列 显示该员工前一位员工的工资
```sql
select e.*,
lag (salary) over (partition by dept_name order by emp_id) as prev_emp_salary
-- lag(salary,2,0):查找前2行的salary，没有则返回默认值：0
from employee e; 
```
检查前一个员工工资是否高于或低于后一位:用lead新创建一列 显示该员工后一位员工的工资
```sql
select e.*,
lead (salary) over (partition by dept_name order by emp_id) as prev_emp_salary
-- lead(salary,2,0):查找前2行的salary，没有则返回默认值：0
from employee e; 
```
检查后一个员工工资是否高于或低于前一位:
```sql
select e.*,
lag (salary) over (partition by dept_name order by emp_id) as prev_emp_salary
case when e.salary>lag (salary) over (partition by dept_name order by emp_id) then 'Higher than previous employee'
case when e.salar<lag (salary) over (partition by dept_name order by emp_id) then 'lower than previous employee'
case when e.salary=lag (salary) over (partition by dept_name order by emp_id) then 'same as previous employee'
from employee e; 
```
