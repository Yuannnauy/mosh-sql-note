# 第二章 数据库的基本使用（表查询）

## 选择语句（SELECT）

```sql
SELECT 想要获取的列
FROM 想要查询的表
-- WHERE 筛选条件
-- ORDER BY 排序条件
```

示例：

```sql
SELECT *
FROM customers
WHERE customer_id = 1
ORDER BY first_name;
```

## 选择子句（The SELECT Clause）

```sql
SELECT
    last_name,
    first_name,
    points,
    points * 10 + 100 AS 'discount_factor'  -- 可以直接执行关于列的公式
FROM customers;
```

```sql
SELECT DISTINCT state  -- DISTINCT 用于消除state列的重复项
FROM customers;
```

练习：

```sql
SELECT name, unit_price, unit_price * 1.1 AS 'new price'
FROM products;
```

## WHERE 子句（The WHERE Clause）

WHERE 用于筛选数据。

示例：

```sql
SELECT *
FROM customers
WHERE points > 3000;
```

比较符号：`>` `>=` `<` `<=` `=` `!=` `<>`

示例：

```sql
SELECT *
FROM customers
WHERE state = 'VA';          -- 位于VA的顾客

SELECT *
FROM customers
WHERE state <> 'VA';         -- 除了VA以外的所有

SELECT *
FROM customers
WHERE birth_date > '1990-01-01';
```

练习：

```sql
SELECT *
FROM orders
WHERE order_date = '2019-01-01';
```

## AND, OR, NOT 运算符

将多个筛选条件结合。

**AND**：两项都要符合

```sql
SELECT *
FROM customers
WHERE birth_date > '1990-01-01' AND points > 1000;
```

**OR**：两项满足一项

```sql
SELECT *
FROM customers
WHERE birth_date > '1990-01-01' OR points > 1000;
```

**运算符优先级**：AND 比 OR 优先

```sql
SELECT *
FROM customers
WHERE birth_date > '1990-01-01' OR points > 1000 AND state = 'VA';
-- 需要既 points>1000 又 state='VA'，或者满足 birth_date > '1990-01-01'
```

**NOT**：逻辑否定

```sql
SELECT *
FROM customers
WHERE NOT (birth_date > '1990-01-01' OR points > 1000 AND state = 'VA');
-- 等价于：
-- birth_date <= '1990-01-01' AND points <= 1000 AND state = 'VA'
```

练习：

```sql
SELECT *
FROM order_items
WHERE order_id = 6 AND quantity * unit_price > 30;
```

## IN 运算符

```sql
-- 原本写法：
SELECT *
FROM customers
WHERE state = 'VA' OR state = 'GA' OR state = 'FL';

-- 简洁写法：
SELECT *
FROM customers
WHERE state IN ('VA', 'FL', 'GA');

-- 排除这些结果：
SELECT *
FROM customers
WHERE state NOT IN ('VA', 'FL', 'GA');
```

练习：

```sql
SELECT *
FROM products
WHERE quantity_in_stock IN (49, 38, 72);
```

## BETWEEN 运算符

```sql
-- 原本写法：
SELECT *
FROM customers
WHERE points >= 1000 AND points <= 3000;

-- 简洁写法：
SELECT *
FROM customers
WHERE points BETWEEN 1000 AND 3000;
```

练习：

```sql
SELECT *
FROM customers
WHERE birth_date BETWEEN '1990-01-01' AND '2000-01-01';
```

## LIKE 运算符

- `%` 表示任意字符数
- `_` 表示单个字符

```sql
-- 姓氏以B开始
SELECT *
FROM customers
WHERE last_name LIKE 'b%';

-- 姓氏中任意位置包含b
SELECT *
FROM customers
WHERE last_name LIKE '%b%';

-- 姓氏只有两个字母，最后一个字母是y
SELECT *
FROM customers
WHERE last_name LIKE '_y';
```

练习：

```sql
SELECT *
FROM customers
WHERE address LIKE '%trail%' OR address LIKE '%avenue%';

SELECT *
FROM customers
WHERE phone LIKE '%9';
```

## REGEXP 运算符（Regular Expression）

```sql
-- LIKE 写法：
SELECT *
FROM customers
WHERE last_name LIKE '%field%';

-- 同样效果：
SELECT *
FROM customers
WHERE last_name REGEXP 'field';
```

正则通配符：

| 符号 | 含义 |
|------|------|
| `^` | 以……开头 |
| `$` | 以……结尾 |
| `\|` | 逻辑或（OR） |
| `[abcd]` | 匹配括号内任意一个字符 |
| `[a-f]` | 匹配a到f范围内任意一个字符 |

```sql
-- 以field开头
SELECT *
FROM customers
WHERE last_name REGEXP '^field';

-- 以field结尾
SELECT *
FROM customers
WHERE last_name REGEXP 'field$';

-- 包含mac或field或rose
SELECT *
FROM customers
WHERE last_name REGEXP 'mac|field|rose';

-- 姓里包含e且e前面必须是g或i或m
SELECT *
FROM customers
WHERE last_name REGEXP '[gim]e';

-- 姓里包含e且e前面是a-h中任意一个
SELECT *
FROM customers
WHERE last_name REGEXP '[a-h]e';
```

练习：

```sql
-- 1. first names 是 ELKA 或 AMBUR
SELECT *
FROM customers
WHERE first_name REGEXP 'ELKA|AMBUR';

-- 2. last names 以 EY 或 ON 结尾
SELECT *
FROM customers
WHERE last_name REGEXP 'EY$|ON$';

-- 3. last names 以 MY 开头或包含 SE
SELECT *
FROM customers
WHERE last_name REGEXP '^MY|SE';

-- 4. last names 包含 B 且 B 后跟 R 或 U
SELECT *
FROM customers
WHERE last_name REGEXP 'B[RU]';
```

## IS NULL 运算符

```sql
-- 查询phone number为空的行
SELECT *
FROM customers
WHERE phone IS NULL;

-- 查询phone number非空的行
SELECT *
FROM customers
WHERE phone IS NOT NULL;
```

练习：

```sql
SELECT *
FROM orders
WHERE shipped_date IS NULL;
```

## ORDER BY 子句

ORDER BY 默认按主键升序排序。

```sql
-- 按名字升序
SELECT *
FROM customers
ORDER BY first_name;

-- 按名字降序
SELECT *
FROM customers
ORDER BY first_name DESC;

-- 先按state排序，相同state内按名字排序
SELECT *
FROM customers
ORDER BY state, first_name;
```

> MySQL 中可以用任何列排序，即使该列没有在 SELECT 中。

```sql
SELECT first_name, last_name
FROM customers
ORDER BY birth_date;
```

练习：

```sql
SELECT *
FROM order_items
WHERE order_id = 2
ORDER BY quantity * unit_price DESC;
```

## LIMIT 子句

用于限定查询返回的记录数。

```sql
-- 只看前3条
SELECT *
FROM customers
LIMIT 3;

-- 分页：跳过前6条，获取3条（第3页数据，每页3条）
SELECT *
FROM customers
LIMIT 6, 3;
```

**子句顺序**：SELECT → FROM → WHERE → ORDER BY → LIMIT

练习：

```sql
SELECT *
FROM customers
ORDER BY points DESC
LIMIT 3;
```
